# 一、技术栈建议

- `SwiftUI`：界面
- `SwiftData`：本地数据
- `UserNotifications`：本地通知
- `AppStorage`：少量轻配置
- `Observation` / `Observable`：状态管理
- 后续预留：
  - `HealthKit`
  - `CloudKit / iCloud`
  - AI 服务层

# 三、架构思路

我建议你首版用这个思路：

## 1. View
只负责展示和触发动作。

## 2. ViewModel
负责：
- 组织页面数据
- 调用服务
- 处理交互动作
- 刷新 UI

## 3. Model
SwiftData 持久化模型。

## 4. Service
负责：
- 通知调度
- 权限检查
- 每日事件生成
- 今日摘要计算
- 历史统计

这样做的好处是：
- 功能比较独立
- 后面加 Apple Health 时，不会把 View 搞乱
- 后面加 AI 也能接入 TodaySummaryBuilder 一层

## 1. Enums.swift

建议把状态先统一定义。

```swift
enum MedicationEventStatus: String, Codable {
    case pending
    case done
    case skipped
    case unconfirmed
}

enum SleepEventStatus: String, Codable {
    case pending
    case confirmed
    case unconfirmed
}

enum MealEventStatus: String, Codable {
    case pending
    case acknowledged
    case unconfirmed
}

enum NightSnackStatus: String, Codable {
    case unset
    case noSnack
    case ateSnack
}

enum ScheduleType: String, Codable {
    case daily
    case weekly
}

enum MealType: String, Codable, CaseIterable {
    case breakfast
    case lunch
    case dinner
    case nightSnack
}
```

## 2. Medication.swift

```swift
@Model
final class Medication {
    @Attribute(.unique) var id: UUID
    var name: String
    var dosageText: String?
    var scheduleTypeRaw: String
    var weekdays: [Int]
    var timesPerDay: Int
    var reminderTimes: [Date]
    var mealNote: String?
    var note: String?
    var isActive: Bool
    var snoozeIntervalMinutes: Int
    var maxSnoozeCount: Int
    var createdAt: Date
    var updatedAt: Date

    init(
        id: UUID = UUID(),
        name: String,
        dosageText: String? = nil,
        scheduleTypeRaw: String = ScheduleType.daily.rawValue,
        weekdays: [Int] = [],
        timesPerDay: Int,
        reminderTimes: [Date],
        mealNote: String? = nil,
        note: String? = nil,
        isActive: Bool = true,
        snoozeIntervalMinutes: Int = 10,
        maxSnoozeCount: Int = 1,
        createdAt: Date = .now,
        updatedAt: Date = .now
    ) {
        self.id = id
        self.name = name
        self.dosageText = dosageText
        self.scheduleTypeRaw = scheduleTypeRaw
        self.weekdays = weekdays
        self.timesPerDay = timesPerDay
        self.reminderTimes = reminderTimes
        self.mealNote = mealNote
        self.note = note
        self.isActive = isActive
        self.snoozeIntervalMinutes = snoozeIntervalMinutes
        self.maxSnoozeCount = maxSnoozeCount
        self.createdAt = createdAt
        self.updatedAt = updatedAt
    }
}
```

> 注意：`reminderTimes` 如果直接存 `[Date]`，你要只取时间部分使用。  
> 更稳一点的方式是自己做 `TimeComponentDTO`，但首版可以先简单。

# 五、Notification 模块怎么设计

这是你的核心。

---

## 1. NotificationManager
负责统一对外接口：
- 请求权限
- 查询权限
- 注册通知动作
- 调度通知
- 取消通知
- 处理用户点击动作

建议对外暴露的方法：

```swift
protocol NotificationManaging {
    func requestAuthorization() async -> Bool
    func getAuthorizationStatus() async -> UNAuthorizationStatus
    func registerCategories()
    func scheduleMedicationNotification(for event: MedicationEvent, medication: Medication)
    func scheduleSleepNotifications(for event: SleepEvent)
    func scheduleMealNotification(for event: MealEvent)
    func scheduleNightSnackNotification(for event: NightSnackEvent)
    func cancelNotifications(ids: [String])
}
```

---

## 2. NotificationIdentifiers
统一管理通知 ID，避免乱。

```swift
enum NotificationIdentifiers {
    static func medication(eventId: UUID) -> String { "medication-\(eventId.uuidString)" }
    static func sleepPre(eventId: UUID) -> String { "sleep-pre-\(eventId.uuidString)" }
    static func sleepFinal(eventId: UUID) -> String { "sleep-final-\(eventId.uuidString)" }
    static func meal(eventId: UUID) -> String { "meal-\(eventId.uuidString)" }
    static func nightSnack(eventId: UUID) -> String { "nightSnack-\(eventId.uuidString)" }
}
```
